# MOBIX - Sprint 2 Web Development

Site desenvolvido para o Challenge FIAP 2026 em parceria com a JOVI Smartphone.
O projeto propõe uma solução de câmera inteligente voltada para estudantes.

## Tecnologias

- HTML5 semântico
- CSS3 com Flexbox
- JavaScript puro (sem frameworks)

## Funcionalidades JS

- Slideshow automático de imagens
- Login criado dinamicamente via DOM
- Validação de formulário de contato
- Efeito de scroll na navbar
- Menu com destaque na seção ativa
- Alertas e prompts de interação com o usuário
